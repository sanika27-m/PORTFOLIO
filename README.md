## ⚡ How to Deploy to GitHub Pages (2-Minute Guide)

Because this portfolio uses a **clean, zero-build static architecture**, you can deploy it to GitHub Pages in two easy ways:

### Option A: Using the Terminal (Recommended)

1. Open PowerShell in this folder (`c:\Users\SANIKA MAHESHWARI\OneDrive\Desktop\portfolio`).
2. Run these commands:
   ```bash
   # Initialize git repository
   git init

   # Stage and commit all files
   git add .
   git commit -m "feat: initial release of Sanika Maheshwari digital portfolio"

   # Rename branch to main
   git branch -M main

   # Add your remote GitHub repository (replace with your repo URL)
   # e.g., git remote add origin https://github.com/sanika27-m/portfolio.git
   git remote add origin https://github.com/sanika27-m/<YOUR_REPO_NAME>.git

   # Push to GitHub
   git push -u origin main
   ```

3. Enable GitHub Pages:
   - Go to your repository on **GitHub.com**
   - Click on **Settings** > **Pages** (in the left sidebar)
   - Under **Build and deployment > Source**:
     - Choose **Deploy from a branch**
     - Select branch: **`main`** and folder: **`/(root)`**
     - Click **Save**
   - *Alternatively*: Choose **GitHub Actions** (the included `.github/workflows/deploy.yml` will deploy automatically!).

4. Your live site will be ready at:
   - `https://sanika27-m.github.io/<YOUR_REPO_NAME>/`
   *(or `https://sanika27-m.github.io` if your repo is named `sanika27-m.github.io`)*

---

### Option B: Local Preview

You can open and preview your portfolio locally at any time:
- **Double click** `index.html` in your file explorer to open it in your browser.
- Or run a local lightweight server using PowerShell / Node:
  ```powershell
  npx serve .
  ```
  and visit `http://localhost:3000`.
